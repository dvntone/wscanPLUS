# Dumping Area

Use this file as a temporary parking lot for information that may matter later but is not yet ready for durable normalization.

## What belongs here

- incomplete findings
- uncertain or low-confidence notes
- partial ideas
- parking-lot tasks
- material that may become relevant after verification
- overflow from session work that should not be lost

## Rules

- Mark uncertainty clearly
- Do not present dumping-area content as authoritative project truth
- Move validated material into durable docs when confirmed
- Remove obsolete or disproven notes when no longer useful
