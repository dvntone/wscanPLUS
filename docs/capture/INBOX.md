# Capture Inbox

Use this file for immediate, approved markdown capture when new findings, decisions, or evidence summaries appear during a working session.

## Rules

- Keep entries short and timestamped
- Prefer searchable bullets over prose walls
- Move normalized material into the correct durable file later
- Delete or trim stale entries once they have been normalized elsewhere
