# Research Notes

This area holds durable research and design notes that support the codebase but are not themselves active device-test evidence.

## Layout

- `codex/` - Codex-authored findings, gap analysis, policy notes, review notes, and one-page summaries
- `verified_sources.md` - curated external references worth keeping in-repo

## Local-only backlog

Large uncurated source dumps and scratch reference lists belong under `docs/local/`, which is git-ignored.
