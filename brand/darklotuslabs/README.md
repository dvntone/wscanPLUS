# darklotusLABS Brand Workspace

This folder contains public-safe planning material for the darklotusLABS / wscan+ landing page and brand system.

It is intentionally limited to:

- landing page strategy
- public website copy
- visual direction
- asset usage rules
- implementation handoff notes

Do not commit private source material here.

## Public-safe contents

- `landing-page-redesign.md` — product-first landing page direction for `darklotuslabs.com`
- `wscanplus-site-copy.md` — approved copy blocks and CTA language
- `asset-guidelines.md` — rules for using the wscan+ mark and `.nyx` companion
- `implementation-handoff.md` — build checklist for a web/design agent

## Private material that does not belong here

Do not commit:

- raw Figma files
- uncompressed source art
- private mockups
- deployment secrets
- API keys
- backend credentials
- app infrastructure details
- original prompt/source material that should not be public

If a file needs to remain private, keep it in a private repository, private design workspace, or local/private drive. This monorepo is public.

## Product naming

Use product-safe language:

- Optional Sync
