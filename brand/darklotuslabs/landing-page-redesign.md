# darklotuslabs.com Landing Page Redesign

## Goal

Redesign `darklotuslabs.com` around wscan+ as a product-first wireless intelligence platform under the **darklotusLABS** brand.

The site should communicate:

> wscan+ is a local-first wireless analysis platform for WiFi, BLE, signal mapping, anomaly detection, and evidence review.

The landing page should feel professional, credible, minimal, and operator-grade.

## Core brand roles

- **wscan+** — product/platform
- **darklotusLABS** — organization/site
- **.nyx** — companion assistant identity
- **app.darklotuslabs.com** — web hub / remote evidence dashboard

## Hero visual

Use a product-first composition:

```text
Laptop dashboard in background
Phone app in foreground
.nyx robot stepping out of the phone screen
Cyan portal/ripple glow
Hand gripping phone bezel
Foot crossing phone screen edge
Small cast shadow proving intentional depth
```

This avoids the previous problem where only an earpiece showed behind the phone and looked accidentally clipped.

## Visual rules for .nyx

Do:

- show .nyx intentionally emerging from the phone
- keep cyan eyes
- keep earpieces/headset design
- use subtle cyan glow
- make physical interaction obvious: hand, foot, shadow, bezel contact
- keep .nyx as companion/support identity

Do not:

- show only one random earpiece behind the phone
- crop the robot without depth cues
- make the mascot dominate the page
- use toy-like proportions
- use chaotic cyberpunk effects

## Visual style

### Palette

```text
Base: #05070B, #0B1220, #111827, #1E293B
Accent: #22D3EE, #2DD4BF
Text: #F8FAFC, #94A3B8
Alert accents: #EF4444, #F59E0B, #10B981
```

### Typography

Recommended:

- Headings: Space Grotesk, Sora, or Inter Tight
- Body: Inter or IBM Plex Sans
- Data/labels: JetBrains Mono or Geist Mono

### Motion

Use restrained motion only:

- scan pulse
- RF ripple
- hover elevation
- subtle graph shimmer
- panel transitions

Avoid:

- Matrix rain
- heavy glitch effects
- terminal spam
- aggressive hacker visuals
