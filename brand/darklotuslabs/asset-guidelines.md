# darklotusLABS / wscan+ Asset Guidelines

## Brand roles

- **wscan+** is the product/platform.
- **darklotusLABS** is the organization/site identity.
- **.nyx** is the robot companion/assistant identity.

The landing page should be product-first. The mascot supports the story but should not replace the product identity.

## Primary logo direction

Preferred product mark:

```text
wscan+
```

Preferred icon direction:

```text
W+
```

with subtle RF/WiFi integration.

## Mascot usage

Use .nyx for:

- onboarding
- assistant/help states
- tutorial guidance
- scan explanations
- empty states
- landing page companion visual

Do not use .nyx as the only brand signal.

## Hero composition rule

If .nyx appears with the phone, the robot must clearly interact with the phone.

Required cues:

- torso visibly emerging from the phone screen
- one hand touching or gripping the phone bezel
- one foot crossing the phone screen edge
- cyan portal/ripple glow around the phone screen
- small cast shadow on the phone or surface
- earpieces/headset placement must look intentional

Avoid:

- one isolated earpiece visible behind the phone
- random cropping
- accidental overlap
- mascot pasted beside device with no interaction

## Visual style

Use:

- near-black backgrounds
- slate panels
- cyan accents
- clean line icons
- dashboard visuals
- signal graphs
- AP/BLE tables
- evidence timelines

Avoid:

- cartoon-first branding
- noisy cyberpunk effects
- Matrix rain
- excessive glitch effects
- fake terminal clutter
- toy-like mascot proportions

## Color guidance

```text
#05070B — page background
#0B1220 — dark panel
#111827 — card surface
#1E293B — elevated surface
#22D3EE — cyan accent
#2DD4BF — teal accent
#94A3B8 — secondary text
#F8FAFC — primary text
```

## Typography guidance

Recommended:

- Headings: Space Grotesk, Sora, Inter Tight
- Body: Inter, IBM Plex Sans
- Data: JetBrains Mono, Geist Mono

## Source handling

This public monorepo should only contain public-safe brand guidance and compressed/export-ready public assets.

Do not commit private source files or raw design source material here.
